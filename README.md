# تطبيق حسابات الشركة

تطبيق أندرويد بسيط لتسجيل **الإيرادات** و **المصاريف** وحساب صافي الربح أو الخسارة.

## المميزات

- إضافة إيراد أو مصروف مع المبلغ والتاريخ والوصف والتصنيف
- عرض إجمالي الإيرادات والمصاريف وصافي الربح/الخسارة
- قائمة بكل العمليات مع إمكانية التعديل والحذف
- فلترة العمليات (الكل / إيرادات / مصاريف)
- البيانات تتخزن محليًا على الجهاز (أوفلاين)

---

## طريقة التشغيل

### 1. تثبيت المتطلبات

- ثبت [Flutter](https://docs.flutter.dev/get-started/install) على جهازك
- ثبت Android Studio
- فعّل وضع المطور على الموبايل أو استخدم Emulator

### 2. تشغيل المشروع

```bash
# انسخ المجلد ده على جهازك
cd accounting_app

# حمل المكتبات
flutter pub get

# شغل التطبيق على الموبايل أو الإيميوليتر
flutter run
```

### 3. بناء ملف APK للتثبيت

```bash
flutter build apk --release
```

الملف هيظهر في:
`build/app/outputs/flutter-apk/app-release.apk`
